# MovieReviewer

### About  
Website for movie reviews with user authentication. App allows user to add reviews for their favorite movies and also add comments to reviews. 
## Technologies used

### Frontend: 

- Angular(ver. 21.2)
- Tailwind(ver. 4.3.1)
### Backend:  

- Spring Boot(ver. 4.0.6)
### Database:  
- H2
### Testing:  
- JUnit5
